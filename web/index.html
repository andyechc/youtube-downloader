Cómo funciona

  1. 1

    Pega el enlace

    Soporta videos, Shorts y YouTube Music. Validamos el link en tu navegador, sin enviarlo a ningún lado salvo al servicio público de resolución.

  2. 2

    Elige calidad

    La misma lógica del CLI: best / 1080 / 720 / 480 / 360 y modo video o solo audio. Vemos el preview antes de bajar nada.

  3. 3

    Guarda el archivo

    El archivo viaja directo a tu carpeta Descargas con barra de progreso real (%, velocidad y tamaño). Puedes cancelar en cualquier momento.

Web vs CLI

La web es para lo rápido. El CLI es para lo exigente.
